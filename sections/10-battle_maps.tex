\section{Battle Maps}

Every phase will have common battle map for all players. 
They will have their own deployment, objectives, special rules and placement of map features.

Deployment rules are similar to what you have seen in other scenarios from matched guide.
Objectives sometimes will contain special power, sometimes will contain a treasure that can be win by contesting the objective at the end of the game.
Contestation rules will differ from normal GW games and it is possible that units other than core will be able to contest the objective.
Map conditions will describe the environment of the battle and any special rules that apply to the map.
Scenario goal will sometimes add extra rules to the game or new conditions to win it. 
As this is slow grow league, we will start slow, and expand the variety as we go. 

Map layout will be given before the game by the Overseer.
Players may choose following:
\begin{itemize}
  \item stick to the layout and play as is,
  \item use scatter dice to scatter selected layout elements or all of them,
  \item create their own layout by placing elements on the map themselves.
\end{itemize}
If players cannot agree on the choice use the dice roll to decide.

Example of a map layout can be seen in this campaign:
\url{https://genuitx.com/campaign/war_across_the_siege_of_cliff.html}
It takes some time to load but later one is pretty fast. You can see plenty of examples of maps there.
